## The app will not open

It needs Windows 10 or 11, 64-bit. Download the installer again from [useshape.org/download](https://useshape.org/download).

## Sign-in never finishes

Finish the step in the browser, then return to the app. If it still fails, sign out and sign in again.

## Chat says usage is not allowed

Check the plan and remaining credits on [Billing](/dashboard/settings/billing). Free includes Auto only.

## The preview cannot reach localhost

Start the dev server, then open that URL in the [browser](/docs/agent/browser).

## GitHub data is missing

[Sign in with GitHub](/docs/git/github) and open a folder whose remote is on github.com.
