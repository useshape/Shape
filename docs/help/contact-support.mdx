## Contact form

Use the [contact page](/contact) for billing, account, or product questions.

Include your account email, OS, and Shape version (**Help → About**). Do not send passwords or API keys.

## Security

Report security issues privately via [SECURITY.md](https://github.com/useshape/Shape/blob/main/SECURITY.md), or use the contact form with topic **Security**.
