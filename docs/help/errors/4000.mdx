## What it means

The editor, agent, or a tool could not access a file or folder. Common causes: missing permissions, a deleted file, or a path outside the open workspace.

## What to do

1. Confirm the folder still exists and you can edit it.
2. Re-open the project in Shape.
3. On Windows, check whether antivirus is locking files.
4. If an agent used a path outside the workspace, reject it and ask again with an in-project path.
