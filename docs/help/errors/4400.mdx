## What it means

Shape could not open a terminal session or run a shell command. Often the configured shell path is wrong, missing, or blocked by policy.

## What to do

1. Open **Settings** and confirm your default shell path.
2. Try launching the same shell outside Shape.
3. On Windows, prefer a full path to `powershell.exe` or `cmd.exe` if `PATH` is incomplete.
4. Re-open the terminal tab after fixing the shell.
