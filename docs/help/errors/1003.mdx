## What it means

Sign-in did not finish. The browser flow may have failed, timed out, or returned an error.

## What to do

1. Try **Sign in** again from the app.
2. Complete login in the browser window that opens, then return to Shape.
3. Check that you can reach [useshape.org](https://useshape.org) and that you have an invite if signup is required.
4. If it keeps failing, sign in on the [dashboard](/dashboard) first, then retry from the app.
