## What it means

Checking for updates, downloading, or installing a new Shape build failed.

## What to do

1. Try **Help → Check for Updates** again.
2. Confirm you are online and can reach Shape’s update servers.
3. If install keeps failing, download the latest installer from [download](/download) and run it manually.
