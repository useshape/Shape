**Error 2002: Network timeout**

A network or timeout error interrupted the request before it completed.

## What to try

1. Check your connection and retry.
2. Disable or adjust VPN / proxy settings if requests fail only from this network.
3. Try again later if the path to Shape or the model provider is unstable.
