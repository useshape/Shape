## What it means

This error code is leftover from an older editor. Shape’s current editor is CodeMirror and does not start language servers.

If editing feels limited, that is expected: there is no TypeScript language service or go-to-definition.

## What to do

1. Use in-file search (**Ctrl+F**) and workspace search (**Ctrl+Shift+F**).
2. Ask the agent to find symbols or explain types.
3. Ignore this code if you see it in old logs.
