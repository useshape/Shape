## What it means

File search, content search, or AI codebase indexing could not run. Causes include a missing search binary, a corrupt index, or a folder Shape cannot read.

## What to do

1. Confirm the project folder is still open and readable.
2. Retry search, or re-run indexing from **Settings → Agents → Context**.
3. On Windows, check antivirus exclusions for the project and Shape install.
4. If content search mentions ripgrep, reinstall Shape or ensure the bundled search tool is present.
