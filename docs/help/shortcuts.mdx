description: Commands worth remembering.
order: 2

| Action | Shortcut |
| --- | --- |
| Open folder | Ctrl+K Ctrl+O |
| Chat | Ctrl+L |
| New chat | Ctrl+Shift+L |
| Command palette | Ctrl+Shift+P |
| Go to file | Ctrl+P |
| Source control | Ctrl+Shift+G |
| Terminal | Ctrl+` |
| Settings | Ctrl+, |
| Design mode | Ctrl+Shift+D |

In a Git diff, Ctrl+Y stages the current hunk and Ctrl+Shift+Y unstages it. Elsewhere, Ctrl+Y is redo.
