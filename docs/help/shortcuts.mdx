These are the defaults. You can change them in Settings.

| Action | Shortcut |
| --- | --- |
| Open folder | Ctrl+K Ctrl+O |
| Chat | Ctrl+L |
| New chat | Ctrl+Shift+L |
| Command palette | Ctrl+Shift+P |
| Go to file | Ctrl+P |
| Source control | Ctrl+Shift+G |
| Terminal | Ctrl+` |
| Settings | Ctrl+, |
| Design mode | Ctrl+Shift+D |

## How to change one

Open Settings, find the keybindings list, and assign a new chord. If the key is taken, pick another or clear the old one.

## Chord vs one key

**Open folder** is two steps: `Ctrl+K`, then `Ctrl+O`. Wait for the chord, then press the second part. If you only press `Ctrl+K`, you are waiting for the follow-up.

## Chat focus

`Ctrl+L` moves you to the composer. Use it when you are in the editor and you want to send a follow-up without clicking the thread.
