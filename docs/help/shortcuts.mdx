These are the defaults. Change them in **Settings → Application → Keyboard Shortcuts**.

| Action | Shortcut |
| --- | --- |
| Open folder | Ctrl+K Ctrl+O |
| Show or hide chat | Ctrl+L |
| New chat | Ctrl+Shift+L |
| Command palette | Ctrl+Shift+P |
| Go to file | Ctrl+P |
| Terminal | Ctrl+` |
| Settings | Ctrl+, |
| Design mode (in-app browser) | Ctrl+Shift+D |
| Cycle Code / Ask / Plan | Ctrl+Shift+. |

## How to change one

Open **Settings → Application → Keyboard Shortcuts** and assign a new chord. If the key is taken, pick another or clear the old one.

## Chord vs one key

**Open folder** is two steps: `Ctrl+K`, then `Ctrl+O`. Wait for the chord, then press the second part. If you only press `Ctrl+K`, you are waiting for the follow-up.

## Chat

`Ctrl+L` shows or hides the chat sidebar. Click the composer (or start a new chat) when you want to type.
