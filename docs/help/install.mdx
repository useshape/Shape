Shape is a desktop app for Windows 10 or 11, 64-bit.

There is no browser-only editor. You download the app, then open a folder on disk.

## Download

1. Get the installer from [useshape.org/download](https://useshape.org/download).
2. Run it.
3. If Windows SmartScreen appears, choose **More info**, then **Run anyway**.
4. Open Shape from the Start menu.

If the installer will not run, you are on 32-bit Windows, or the download was cut short. Download it again.

## Sign in after install

Sign in so chat and billing work. You can open files without an account. You cannot send a message without one.

## Updates

Updates install on their own. **Help → Check for Updates** runs one now.

If an update fails, download a fresh installer and run it over the existing install.

## Uninstall

Uninstall from Windows Settings like any other desktop app. Your project files on disk are not deleted. Local Shape data for the app may remain under your user folder.
