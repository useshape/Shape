## Can I work offline?

Editing files works without a connection. Chat does not. Git push and pull need a connection too.

## Do credits roll over?

No. They reset each month. Plans are on [Models](/docs/get-started/models).

## Does Shape upload my project?

Not by default. Chat sends the files and context you include in a turn, plus what the agent reads to do the task. Local editing does not require chat.

## Can I use my own model key?

Named models on a paid plan run through Shape. Local editing does not need a key. There is no setting to paste a personal provider key for chat.

## What OS is supported?

Windows 10 or 11, 64-bit. See [Install](/docs/help/install).

## Can I sign in from a fork of the app?

No. A fork cannot sign in to Shape Cloud. Official builds can. You can still run a local build and edit files. See [local development](/docs/developing/local-development).

## Where do I change my password or email?

Account security is on the website under dashboard settings. Sign-in, password, and email all use the same account you sign into the app with.
