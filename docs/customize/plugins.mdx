Plugins let chat use GitHub, Slack, Linear, Stripe, and similar accounts. You connect the account once, then mention the task in a message.

You must be signed in. A plugin is not a local tool. A tool that runs on your machine is [MCP](/customize/mcp).

## Connect an account

1. Open **Settings → Agents → Plugins**.
2. Pick the service.
3. Sign in in the browser window and allow access.
4. Return to Shape.

You can disconnect from the same place. Disconnecting stops new chat turns from using that account. It does not delete past threads.

## Use it in chat

Say what you need in plain language. You do not need a special syntax.

Examples:

- “Open a pull request for this branch.”
- “List my Linear issues tagged bug.”
- “Post a summary of this diff to the engineering Slack channel.”

If the plugin is not connected, Shape cannot call it. Connect it first, then send the message again.

## GitHub in two places

Signing in for [GitHub](/git/github) loads pull requests and related data for the open folder. A GitHub plugin is for chat. You may need both, depending on what you are doing.

## If it fails

Sign in again. Check that the account has access to the repo or workspace you named. Then send a shorter message that names the repo or channel.
