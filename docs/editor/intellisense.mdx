The editor uses **CodeMirror 6**. Completions and highlighting come from language packs for the file type, not from language servers.

## Completions

Start typing to see suggestions. Press **Tab** or **Enter** to accept.

Supported highlighting and completions include:

| Language | Typical files |
| --- | --- |
| **TypeScript / JavaScript** | `.ts`, `.tsx`, `.js`, `.jsx` |
| **JSON** | `.json`, `.jsonc` |
| **HTML** | `.html`, plus `.vue` / `.svelte` / `.astro` highlighting |
| **CSS** | `.css`, `.scss`, `.less` |
| **Markdown** | `.md`, `.mdx` |
| **Python / Rust / SQL** | matching extensions |

There is no TypeScript language service, go-to-definition, rename, or Quick Fix pipeline in the editor. Use search, the agent, or your project’s own toolchain for type-aware work.

## Find in file

**Ctrl+F** opens the in-editor search panel.

## Diagnostics

The **Problems** panel collects ESLint findings (when enabled) and design checks. It does not host an LSP.
