AI Chat lives in the right sidebar. Ask about the project, get explanations, and request edits with review before anything is applied.

## Open chat

- Titlebar **AI Chat** toggle
- **View → AI Chat**
- **Ctrl+L**

Drag the divider to resize. Use the same control to close the panel.

## Sign in

Cloud AI needs a [Shape account](/docs/introduction/accounts). Local editing does not.

## Send a message

1. Type in the input at the bottom of the panel.
2. Pick a [mode](/docs/ai/chat-modes) (start with **Ask** for read-only questions).
3. Choose a model, or leave **Auto**.
4. Press **Enter** to send (**Shift+Enter** for a new line).

Shape attaches workspace context when it helps: open files, project layout, and diagnostics.

Use `@` mentions for a file, folder, the codebase, or the current editor selection.

## Attachments

Use the attachment control to add images or files (screenshots, design references, a specific file).

## History and stop

Past chats are saved per project. Run **Chat: Show History** from the command palette to reopen one.

Click **Stop** while a reply is streaming to cancel. Partial output stays in the thread.

## Terminal commands

In **Code** and related modes, the assistant may propose shell commands. Each one shows **Run** or **Reject** before it executes.
