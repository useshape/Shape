Shape stores preferences in a settings editor that opens as a tab in the workbench. Changes apply immediately or on the next relevant action.

## Open settings

- Click the **gear** icon on the [activity bar](/docs/workspace/activity-bar)
- Click **Settings** in the titlebar
- **Window → Settings** or **Ctrl+,**

Close the settings tab with **Ctrl+W** like any editor tab.

## Categories

The left tree groups settings like this:

| Group | Sections |
| --- | --- |
| **Account** | Profile, plan, updates channel |
| **Agents** | Models, rules, context, MCP |
| **Editor** | Font, indentation, caret, saving, files, Design |
| **Features** | Terminal, Source Control, language servers, Node.js, Python, ESLint & Prettier |
| **Application** | Updates, notifications, privacy, developer |

Select a leaf in the tree to jump to that section. Controls are toggles, dropdowns, and text fields.

Design autocomplete, Tailwind controls, and diagnostics are under **Editor → Design**, not a separate top-level category. Agent auto-run, edit approval, and adversarial review are under **Agents**. See [AI Settings](/docs/ai/ai-settings) and [Design Tools](/docs/editor/design-tools).

## Persistence

Settings are saved locally on your machine. They apply to all projects unless a project-specific tool config overrides them (for example `.prettierrc`).

## Reset to defaults

Individual settings can be restored by selecting the default value in each control. There is no single "reset all" button. Reinstalling Shape does not remove your saved settings file.
