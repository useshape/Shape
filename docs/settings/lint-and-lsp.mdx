Shape can run ESLint and Prettier against the open project. The editor itself is CodeMirror — these tools are not language servers.

**Settings → Features → ESLint & Prettier** controls diagnostics and formatters.

## ESLint

| Setting | Description |
| --- | --- |
| **Enable ESLint** | Run ESLint on supported files |
| **Fix on save** | Apply auto-fixable rules when saving |

ESLint reads your project's config (`.eslintrc`, `eslint.config.js`, etc.). Errors appear in the **Problems** panel.

## Prettier

| Setting | Description |
| --- | --- |
| **Enable Prettier** | Use Prettier as the document formatter |

When enabled, **Format Document** (**Alt+Shift+F**) and format-on-save use Prettier with project config (`.prettierrc`, `prettier.config.js`).

## Language servers

Shape does not run a TypeScript, CSS, HTML, JSON, or Tailwind language server in the editor. Completions come from CodeMirror language packs. See [Completions](/docs/editor/languages-and-tooling).

## Design tooling

Design autocomplete and diagnostics live under **Settings → Editor → Design**. See [Design Tools](/docs/editor/design-tools) and [Visual Design](/docs/editor/visual-design).

## Troubleshooting

If diagnostics never appear:

1. Confirm ESLint is enabled.
2. Open **Problems** (**Ctrl+Shift+M**).
3. Ensure the project has the expected config files (`tsconfig.json`, ESLint config).
