## Requirements

- Windows 10 or later (64-bit)
- Git (for clone and source control)
- Node.js (recommended for scripts and language tooling)

You can open local projects without an account. Sign in is required for cloud AI.

## Install

1. Download the Windows installer from [useshape.org/download](https://useshape.org/download).
2. Run the installer. If Windows SmartScreen warns that the app is unrecognized, choose **More info**, then **Run anyway** (common for new release hashes).
3. Open Shape from the Start menu.

## First check

1. **File → Open Folder** and pick a project.
2. Open the terminal (**View → Terminal** or **Ctrl+`**).

If both work, you are set. Continue with [Quick Start](/docs/introduction/quick-start).

## Updates

Shape checks for updates automatically. Use **Help → Check for Updates**, or follow the titlebar prompt when one is available.

In **Settings → Account**, switch the update channel to Pre-release or turn off automatic checks.

## Troubleshooting

**Shape will not start**

- Restart Windows and try again.
- Re-run the installer.
- Check that antivirus is not blocking Shape.

**Git or Node missing in the terminal**

Install [Git for Windows](https://git-scm.com/download/win) and [Node.js](https://nodejs.org), then restart Shape.
