<Update label="October 9, 2026" description="v1.0.0" tags={["Desktop", "Agent", "Git"]}>
  Windows x64 and ARM64 installers. [Download](https://www.useshape.org/download) or [GitHub release](https://github.com/useshape/Shape/releases/tag/v1.0.0).

  Desktop coding agent with chat modes (Code, Ask, Plan, Visual, Review), CodeMirror editor, in-app browser, plugins, MCP, and git from chat or the terminal.

  Folder watching no longer follows `node_modules`, `target`, or `.next`, so RAM stays bounded on large projects.
</Update>

<Update label="August 19, 2026" description="v0.1.0" tags={["Desktop", "Editor", "Agent", "Git"]}>
  Windows x64 and ARM64 installers. [Download](https://www.useshape.org/download) or [GitHub release](https://github.com/useshape/Shape/releases/tag/v0.1.0).

  ### Editor

  * CodeMirror editor and file preview
  * Visual design mode on the live preview

  ### Agent

  * MCP, edit approval, auto-run, and chat workflow

  ### Git

  * Commit graph, PRs, and hunk staging

  ### Workbench

  * Chrome, tabs, notifications, and settings
</Update>
