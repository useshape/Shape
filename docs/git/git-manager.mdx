**Git Manager** is Shape's Git workspace: local source control, the commit graph, pull requests, issues, and Actions. Open it from **Window → Git Manager** or the Shape logo in the Source Control sidebar.

Day-to-day stage and commit still live in the [Source Control](/docs/git/source-control) sidebar.

The window remembers the last section you had open. The current section title lives in the top bar with search and actions.

## Local

| Section | Purpose |
| --- | --- |
| **Source Control** | Stage, commit, pull, and push |
| **Git Graph** | Commit history as a lane diagram — open a commit, then a file, to review the diff in a side panel |
| **Branches** | Local and remote branches |

## GitHub

Sign in with [GitHub](/docs/git/github-sign-in) to load remote data for the open repository.

| Section | Purpose |
| --- | --- |
| **Pull requests** | PR list, conversation, commits, files, and checks. **Create pull request** drafts title and body with AI from your branch diff, then publishes when you confirm. Opening a PR starts an AI review and surfaces failed checks. |
| **Issues** | Open and closed issues, conversation, and details |

On a pull request or issue you can:

- Read the conversation
- Switch tabs for commits, files, and check runs
- **Review** or **Summarize** with AI (needs a [Shape account](/docs/introduction/accounts))
- **Open on GitHub** in your system browser

## Actions

| Section | Purpose |
| --- | --- |
| **Workflow runs** | Recent CI runs, jobs, logs, and artifacts |
| **Jobs** | Jobs and logs for the selected run |
