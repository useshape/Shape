Shape does not commit when it edits a file. You keep or skip the diff in chat first. Then you commit what is actually on disk.

## From chat

In **Code** mode, ask it to commit. Name the files if you only want some of them. Read the message it drafts before you let it run.

This uses the open folder’s git repo. Open the repo root, not a nested package, unless that package is its own repo.

## From the terminal

Open the terminal (`Ctrl+``) and run `git` the way you usually do. Stage, commit, and push from there if you prefer.

## Commit graph

**View → Git Manager** opens the commit graph in the workspace. Use it to see history on the current folder.

## Remotes and GitHub

A GitHub login is only needed for remotes hosted on GitHub, pull requests, issues, and Actions. Local commits work without it. See [GitHub](/git/github).

## After an agent edit

Keep or skip the diffs in the chat thread first. Then commit what is actually in the working tree. Skipping a diff in chat and committing the same file from disk will still include that file if it is still changed on disk.
