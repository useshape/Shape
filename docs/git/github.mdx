Sign in with GitHub when the open folder has a `github.com` remote. This login is separate from the account you use for chat.

A local-only repo has nothing to load from GitHub.

## Sign in

Open a pull request from the workspace, or ask chat after you connect the [GitHub plugin](/customize/plugins). Finish the browser step, then return to Shape.

If data is missing, sign in again, and confirm the open folder is the repo you think it is (`git remote -v` in the terminal).

## Open a pull request

1. Commit and push the branch. See [Commits](/git/commits).
2. Open a pull request from Shape, or ask chat to open one if the GitHub plugin is connected.
3. Read the title and body. Shape can draft them from the branch. You confirm before it is published.

Do not publish a PR for a folder that is not the repo you meant to open.

## Chat vs GitHub login

Asking chat to “open a PR” uses a [plugin](/customize/plugins) if you connected one. GitHub login is for the open folder’s github.com remote. Use whichever matches the task.

## Sign out

Sign out of GitHub from the same place you signed in. Chat sign-in is unchanged.
