<Figure src="/docs/media/introduction/images/app.webp" alt="A project open in the app" />

Download the installer from [useshape.org/download](https://useshape.org/download), sign in, and open a folder.

Ask is a good way to get familiar with the code. Code can make changes and run commands. When a file changes, review the diff and keep or undo it. Larger changes are easier to start in [Plan](/docs/agent/plan).
