Every message uses a model. You pick it from the model menu in chat.

## Auto

Auto is included on every plan, including Free. Use it unless you have a reason to pick a named model.

Auto is the default. Leave it there for most work.

## Named models

Paid plans can pick a named model. Named models spend credits. Harder tasks and longer threads spend more.

Credits reset each month. Unused credits do not carry over.

If a named model is greyed out, the current plan does not include it. Change the plan on [Billing](/dashboard/settings/billing).

## Plans

| Plan | Price | What you get |
| --- | --- | --- |
| Free | $0 | Auto |
| Plus | $15 / month | Auto and named models, 450 credits |
| Pro | $50 / month | Auto and named models, 1,500 credits |
| Max | $150 / month | Auto and named models, 4,500 credits |

Change your plan on [Billing](/dashboard/settings/billing). Usage for the current period is on the same page.

## How to choose

- Everyday edits: Auto.
- A large refactor or a long plan: a named model on a paid plan.
- You are out of credits: Auto still runs on paid plans according to the current period. If send fails, wait for the reset or change plan.

## What a credit is not

A credit is not one message. One turn can spend a fraction of a credit or several, depending on how much context and work the model does.

The usage graph on the dashboard shows credits over recent days. It does not show a number on each slice of the model chart.
