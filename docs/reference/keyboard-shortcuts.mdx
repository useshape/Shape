Shape shortcuts come from `shape/config/keybindings.json` plus workbench and editor commands registered in the command palette. Most use **Ctrl** on Windows.

Open the command palette (**Ctrl+Shift+P**) to find actions by name. Assigned shortcuts appear on the right.

## File and workspace

| Action | Shortcut |
| --- | --- |
| New Text File | **Ctrl+N** |
| New Window | **Ctrl+Shift+N** |
| Open File | **Ctrl+O** |
| Open Folder | **Ctrl+K Ctrl+O** |
| Close Folder | **Ctrl+K Ctrl+W** |
| Save | **Ctrl+S** |
| Save As | **Ctrl+Shift+S** |
| Save All | **Ctrl+K S** |
| Close Tab | **Ctrl+W** |
| Close All Tabs | **Ctrl+K E** |
| Recent Files | **Ctrl+E** |
| Close Window | **Alt+F4** |

## Palette-only commands

These commands have no default shortcut. Run them from **Ctrl+Shift+P**:

- **View: Show Problems**
- **View: Show Output**
- **Editor: Toggle Minimap**
- **Editor: Toggle Inlay Hints**
- **Chat: Show History**
- **Change Language Mode…**
- **View: Toggle Zen Mode** (also **Ctrl+K Z**)

## Chords

Some shortcuts use two steps. Press the first chord, release, then press the second:

| Action | Chord |
| --- | --- |
| Zen Mode | **Ctrl+K**, then **Z** |
| Save All | **Ctrl+K**, then **S** |
| Close All Tabs | **Ctrl+K**, then **E** |
| Format Selection | **Ctrl+K**, then **Ctrl+F** |
| Fold All | **Ctrl+K**, then **Ctrl+0** |
| Unfold All | **Ctrl+K**, then **Ctrl+J** |
