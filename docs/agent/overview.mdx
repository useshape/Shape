Chat with your project and let it handle the work.

Ask is useful for getting familiar with a codebase. Code can make changes and run commands. Plan helps with larger changes. Visual is for UI, and Review is for tracking down a problem and making a small fix.

When a file changes, review the diff and keep or undo it.

`@` adds a file to the message. `/` runs a [slash command](/docs/customize/slash-commands).
