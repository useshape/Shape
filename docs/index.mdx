Shape is a desktop coding agent. Use it to understand your codebase, plan and build, fix bugs, review changes, and work with the tools you already use.

<Frame caption="Shape on the desktop">
  <img src="/images/hero.png" alt="Shape desktop app with the agent, editor, and preview" />
</Frame>

<Tip>
  Windows only right now. Download from [useshape.org/download](https://useshape.org/download), then open a folder you already work in.
</Tip>
