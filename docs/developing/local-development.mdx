You need Node.js 18 or newer, and a current Rust toolchain for [Tauri 2](https://v2.tauri.app/start/prerequisites/).

This is how you run a local build. It is not how you use Shape day to day. For that, install the app from [download](/download).

## Install dependencies

```bash
npm install
```

Run this at the repo root the README names for the desktop app. If the monorepo has more than one package, follow that README, not this page, for the exact folder.

## Run the app

```bash
npm run tauri:dev
```

That opens the desktop app against your local build. The first run compiles Rust and takes longer.

## Cloud while developing

Point `NEXT_PUBLIC_SHAPE_WEBSITE_URL` at `http://localhost:3000` and run the website locally. Localhost Cloud AI does not require an official-build attestation. Production `useshape.org` still does.

A **release** binary also honors that env var when it is loopback (`http://localhost:3000` or `http://127.0.0.1:3000`). Set it in the shell before launching the `.exe` if you need Cloud AI against a local website. Other hosts stay on `https://www.useshape.org`.

Optional: `SHAPE_RAM_DEBUG=1` writes process memory samples to `%LOCALAPPDATA%\shape\ram-debug.log`.

## Tests

```bash
npm run test
```

`npm run test:all` also runs the Rust tests. Run the suite that matches the files you touched.

## Sending the change

Commit on a branch and open a pull request against `main`. Keep the diff focused. See [Overview](/docs/developing/overview).
