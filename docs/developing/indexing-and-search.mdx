## Overview

Workspace search and related discovery features call into Rust FS and search adapters (including ripgrep-backed paths when available). The explorer and outline panels consume project state exposed through Tauri commands and events.

Docs site search is separate: MDX under `docs/` is indexed by `npm run docs:index` into `docs/generated/search-index.json`, which the website loads for docs search and docs chat.
