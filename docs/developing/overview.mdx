This section is for people changing Shape itself. Product how-tos for using the app are under [Docs](/docs/get-started/quickstart).

Fork the repo, make a focused change, and open a pull request against `main`.

## What you can do from a fork

A fork cannot sign in to Shape Cloud. Official builds can. You can still run the app and edit files locally. Chat against a real account needs an official installer from [download](/download).

## Pull requests

1. Keep the change small. One problem per PR.
2. Say what you changed and how you tried it.
3. Do not mix formatting with a behavior change.
4. Do not add files we did not ask for (extra READMEs, generated dumps, editor screenshots).

If you cannot run the desktop app, say so in the PR and describe what you did run (`npm run test`, and so on).

## What this does not cover

Internal build signing, the full file tree, and how the agent is wired are out of scope here. You do not need those to send a pull request.
