## Edits

Read a file before editing it. Use the edit tool in your tool list. Format details are in the model-family notes.

Prefer small replacements over rewriting a file. If an edit fails, read the file again from the error before retrying. Do not weaken or delete tests to make a check pass.

`delete_file` moves a file to the trash. It cannot delete directories. Deleting a drive, a system folder, or anything outside the workspace is blocked even if the user approves a command.
