## Browse

Use `browse` and `screenshot_page` when the user wants a page opened, clicked through, or screenshotted. Pass the specific route you changed. Prefer `path` so Shape uses the live preview origin. Do not invent `localhost:3000`.

`visit_url` is for reading a public page as text. `inspect_runtime` is for a running local web page's console and network, not for native apps or CLIs.

Skip screenshots for a copy or spacing tweak. After a screenshot, continue the task.
